# ChatGPT Setup

Use these files when you want the Theorist Toolbox workflow inside ChatGPT.

## Custom GPT Or Project Instructions

Paste `custom-gpt-instructions.md` into the instruction field. If your ChatGPT setup supports attached knowledge files, attach `knowledge/theorist-toolbox-reference.md`.

## Direct Use

If you do not want to configure a custom GPT, paste one of the prompts from `prompts/` into a normal ChatGPT conversation and fill in the placeholders.

Recommended starting points:

- `prompts/math-proof.md` for a complete proof.
- `prompts/adversarial-verify.md` for proof review.
- `prompts/conjecture-explore.md` when the claim may be false.
- `prompts/co-math-project.md` for a longer research project.
- `prompts/proof-readability.md` after correctness is already accepted.
