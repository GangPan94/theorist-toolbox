# Math Proof Prompt

Use this when you want ChatGPT to prove a result.

```text
Use the Theorist Toolbox math-proof workflow.

Claim to prove:
<paste theorem, proposition, or derivation target>

Context and definitions:
<paste notation, assumptions, equations, model primitives, and domains>

Audience:
<e.g. economics/game-theory journal readers>

Requirements:
- State the proof plan before the proof.
- Define all notation before use.
- Show intermediate algebra.
- Sign every derivative, inequality, monotonicity claim, and limit claim.
- Handle edge cases and boundary behavior.
- Do not use "clearly", "obviously", "easy to see", or "similar argument omitted".
- If a step cannot be proved, mark it explicitly as an open obligation rather than pretending it is done.
```
